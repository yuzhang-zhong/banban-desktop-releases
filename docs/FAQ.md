# 常见问题

[回到首页](../README.md) · [使用指南](USER-GUIDE.md) · [行为与剧情逻辑](BEHAVIOR.md)

以下说明对应 **0.7.38** 的 Windows 安装版。

## 下载与启动

### 应该下载哪个文件？

在 [最新发布页](https://github.com/yuzhang-zhong/banban-desktop-releases/releases/latest) 下载 `Banban-Setup-版本号.exe`。这是带安装向导和自动更新通道的版本。

`latest.yml` 和 `.blockmap` 是更新程序使用的文件，不需要手动打开。GitHub 的「Source code」压缩包也不是桌宠安装包；这个仓库发布安装文件和产品资料，不公开应用源码。

### 运行后，为什么任务栏没有窗口？

这是桌宠的设计。斑斑直接出现在桌面上，菜单贴在她旁边；系统通知区域保留托盘入口。

找不到她时，展开 Windows 隐藏图标区域，左键点斑斑图标即可找回；右键点图标可以打开菜单，再选「看看斑斑」。也可以再次启动程序，已有的斑斑会被找回，不会再生成一只共享同份记忆的猫。

### Windows 提示「Windows 已保护你的电脑」怎么办？

当前安装包尚未进行 Windows 代码签名，因此可能出现 SmartScreen 信誉提示。请先确认文件来自本仓库的 [Releases](https://github.com/yuzhang-zhong/banban-desktop-releases/releases)；不必为安装关闭系统防护。

如果是安全软件明确报出恶意软件名称，或安装本身失败，请通过 [Issues](https://github.com/yuzhang-zhong/banban-desktop-releases/issues) 提供提示文字、版本号和下载来源，方便区分问题。

### 有 macOS、Linux 或手机版本吗？

目前发布的是 Windows 桌面安装版。其他平台没有可下载的正式安装包。

## 玩耍与故事

### 右键为什么没有立刻出现下一段剧情？

新偶遇遵守 30 分钟、1 小时或 3 小时的等待，默认 3 小时。右键会显示大致还要等多久，不能直接跳过。

如果已经开始一段故事，右键的「继续这段故事」会回到原处。同一次相遇的后续可以接着看，无需再等完整间隔。

### 已经到时间，为什么还没出现？

自动剧情会避开睡觉、拖动、玩玩具以及打开的菜单、故事和回忆册。先让当前活动结束，再给她一点时间。开启持续睡觉模式时，也需要先关闭它。

### 她为什么不捡球？是不是没点中？

如果球已经飞出去，或她已经转头看它，操作通常已被接受。她可以追、拍、留下，也可以只看；疲倦、熟悉程度和最近玩耍次数会影响回应。

如果玩具一直没动，试着按住**玩具本身**再操作。软球适合丢，毛线适合贴地拖，羽毛与铃铛适合轻摇，嗅闻垫适合放好等她检查。

### 她总在睡，怎样恢复？

右键如果出现「关闭持续睡觉」，说明开启了持续模式，点它即可恢复日常。普通小睡时，右键选择「叫她起来」。

右键系统托盘里的斑斑图标，可以开启或关闭持续模式。缓慢拖动睡着的斑斑只会换位置，不会自动取消睡眠。

### 她为什么不爬我打开的窗口？

先在小设置里开启「爬前台窗口边」。这个动作只在合适状态下偶尔发生；也可以右键托盘图标，选择「让斑斑去前台窗口边看看」。

窗口要有可用的边缘，并位于斑斑当前桌面范围内。最小化、跨屏、尺寸不合适或正在变动的窗口可能被跳过。它目前不是把所有桌面图标和应用内容都识别成平台的功能。

### 不照顾她，或者一段时间不开程序，会怎样？

日常陪伴不需要定时打卡。故事靠你参与相遇与选择向前走，现实中离开多久不会被简单换算成一连串饥饿或危险剧情。

回来后可以继续未读完的故事。已经到期的新偶遇会在合适时机出现，不会一次补弹很多段。

### 达成结局就结束了吗？

好的结局之后可以「继续这段生活」，也可以开启新的漫游。继续生活尊重当前关系和住处；重新漫游重置本轮故事，保留回忆、结局收藏与亲密。

不是所有结局都会随机直接出现。它们需要相应的遇见、选择与故事时间，有些内容目前还没有日常触发入口。

## 记忆与更新

### 「同步记忆」会传到云端吗？

不会。这里的同步是把当前状态写入本机存档。当前没有账号登录，也没有跨电脑云同步。

记忆包含故事进度、最近 30 条经历、已收集结局和陪伴关系。程序写入时会保留一份可用备份，主存档无法读取时会尝试从备份恢复。

### 怎样给记忆做备份，或换一台电脑？

先在小设置里点「同步记忆」，再正常退出斑斑。在资源管理器地址栏输入：

```text
%APPDATA%\banban-desktop-pet
```

退出后，将整个 `banban-desktop-pet` 文件夹复制到自己的备份位置。里面的 `banban-memory.json` 和 `.bak` 是记忆与备份；程序还保存了另一份本机状态，因此换电脑时应完整备份目录。

换电脑时，先安装并启动一次斑斑，再退出。将目标电脑原有的同名文件夹改名留作备份，再把备份目录完整放进 `%APPDATA%`，保持文件夹名为 `banban-desktop-pet`，然后启动。请勿在斑斑运行时覆盖文件，也不要只把旧记忆文件混进新的目录。开机启动等系统设置请在新电脑重新选择。

存档包含你的游玩经历，反馈问题时不必公开整份文件。

### 自动更新什么时候运行？

安装版启动约 45 秒后会第一次后台检查，之后运行期间约每 6 小时检查一次。也可以右键 → 小设置 →「检查更新」。

有新版本时会后台下载。下载完成后，点「重启更新」才会安装；更新前先保存记忆。普通退出不会顺便安装，正在看故事时也不会强制重启。

### 显示更新失败，怎么办？

先继续使用当前版本，网络恢复后在小设置里重试。GitHub 连接不稳定会影响检查和下载，但本地玩耍与已安装的故事仍可使用。

如果提示文件校验失败，更新会停止；请重新检查，或从 [发布页](https://github.com/yuzhang-zhong/banban-desktop-releases/releases/latest) 下载新的安装包。不要手动替换正在运行的应用文件。

### 为什么显示「安装版可用」？

自动更新要求先运行 `Banban-Setup-版本号.exe` 完成安装。直接打开解压目录中的程序、免安装版或开发版本，不使用这条自动更新流程。

如果你正在使用加入更新功能之前的旧版，请先安装一次 0.7.38 或更新的安装版。

### 爬窗口会读取其他应用的内容吗？

这项功能只读取窗口位置、尺寸、可见状态与用于确认同一窗口的标识，不读取窗口标题、屏幕像素、键盘输入或文档内容。你可以在小设置里关闭它。

故事与泡泡使用本地内容和状态规则。联网主要用于从 GitHub 检查、下载更新，不需要把游玩记忆上传到聊天服务。

## 反馈一个小问题

请到 [Issues](https://github.com/yuzhang-zhong/banban-desktop-releases/issues) 告诉我们：

- 斑斑的版本号，以及 Windows 版本。
- 问题前做了什么，例如「先拿出毛线，再拖动睡着的斑斑」。
- 你期待发生什么，实际又发生了什么。
- 是否每次都会发生；必要时附只包含相关区域的截图或短视频。

越具体的小动作，越容易找到衔接哪里出了问题。
