# 和斑斑一起过一天

[回到首页](../README.md) · [她为什么这样做](BEHAVIOR.md) · [常见问题](FAQ.md)

斑斑大多时候沿着桌面散步，停下来听一听，理毛，或者找个地方睡觉。你可以忙自己的事；等她遇见一段小故事，再陪她做一个选择。

这份指南对应 **0.7.38** 的 Windows 安装版。

## 先把她接到桌面

1. 打开 [最新发布页](https://github.com/yuzhang-zhong/banban-desktop-releases/releases/latest)，下载 `Banban-Setup-版本号.exe`。
2. 运行安装程序，选择安装位置，完成后启动「像素斑斑」。
3. 在斑斑身上点右键，打开身旁的小菜单。先试试「陪她玩」，或在「小设置」里选一个舒服的大小。

运行后不显示普通任务栏窗口。需要找回她时，左键点通知区域的斑斑图标即可；右键点图标则会打开托盘菜单，里面也有「看看斑斑」。图标可能收在 Windows 的隐藏图标区域里。

## 几个最常用的动作

| 你想做什么 | 怎么做 |
| --- | --- |
| 打开菜单 | 在斑斑身上点右键。菜单会根据睡觉、玩耍和故事状态变化。 |
| 摸摸头 | 在头部轻点，或轻轻划过一小段。无需从菜单选择。 |
| 换个位置 | 按住斑斑拖动，再松开。清醒时会呈现被抱起的姿态。 |
| 看回忆 | 双击身体，或右键 → 小设置 → 口袋回忆册，查看最近 30 条经历与结局收藏。 |
| 收起玩具 | 右键 → 收起玩具。留在地上的玩具也可以再次拿起来。 |
| 找回斑斑 | 右键 → 小设置 → 回到角落；也可左键点托盘图标直接找回。 |
| 退出 | 右键斑斑 → 退出斑斑，或右键托盘图标 → 退出像素斑斑。 |

摸头时如果她还不熟悉你，可能先闻闻手；熟悉以后，回应会更亲近。连续点很多次不会让关系立刻跳到亲密。

## 玩具要用不同的方法

拿出玩具后，**操作物件本身**。斑斑会先看、靠近，再决定出不出爪。

| 玩具 | 手上的动作 | 她可能怎样回应 |
| --- | --- | --- |
| 软球 | 拖住球，挥手后松开；停住再松开就是放下。 | 追过去、拍走、压在爪边，或者叼回来。 |
| 毛线团 | 按住线团，沿地面慢慢带动。 | 盯住线头、跟几步、伸爪，或抓住不放。 |
| 纸团 | 轻轻丢出，让它滚一段。 | 拨一下、留在脚边，也可能只看着。 |
| 羽毛逗猫棒 | 按住羽毛，轻轻左右摇。 | 看准位置再伸爪，或先观察一会儿。 |
| 布老鼠 | 拖住后轻轻往地面丢。 | 靠近、扑住，或拍开继续研究。 |
| 小铃铛 | 按住铃铛，轻摇几下。 | 先留意动静，再决定是否靠近。 |
| 嗅闻垫 | 放在旁边，留点距离。 | 走近闻闻，慢慢检查，也可能暂时不理。 |

她自己玩起来时，露出的可交互玩具也能被你接手。球不会因为进入下一段动作就变成第二颗球；留在地上的还是那件物品。

如果她说「现在不想追」，可以让玩具先留着，或者收起来。心情、疲倦、熟悉程度和最近玩了多少，都会影响她的选择。

## 小睡，还是一直睡

**小睡一会儿**在右键菜单里。她会安顿下来，睡够后恢复日常；睡着时右键可选「叫她起来」。这不是永久暂停。

想让她长时间安静陪着，**右键系统托盘中的斑斑图标**，开启「持续睡觉模式（直到你关闭）」。恢复时，直接在斑斑身上右键，选 **「关闭持续睡觉」**；右键托盘图标也有相同入口。

睡着的斑斑可以轻轻挪动：慢慢拖，她能接着睡；持续加快会让她翻动、醒来，猛地拖动会直接惊醒。反复打扰时，她会困困地表示想休息。

## 故事怎么来

右键 → 小设置 → 剧情节奏，有三个档位：

| 档位 | 两段独立偶遇之间的等待 |
| --- | --- |
| 快一点 | 30 分钟 |
| 适中 | 1 小时 |
| 慢慢走（默认） | 3 小时 |

这是新偶遇的基础间隔。到时间时，如果她正睡觉、被抱着、玩玩具，或你还开着菜单、故事、回忆册，自动出现的故事会再等等。调整节奏后，新一轮等待按新档位计算。

右键菜单会显示「新偶遇 · 约……后」。**右键不会跳过这段等待**；但已经开始的故事，可以随时从「继续这段故事」接回来。

每次选择都有对应的结果与短动作。同一次相遇如果还有后半段，可以点「接着看看」；暂时忙的话，也能先收起，之后回到原处。收起和重开不会重复领取这次选择的结果。

## 遇到结局以后

结局会打开单独的回忆窗口。好的结局之后，你可以「继续这段生活」，也可以开始新的漫游，探索另一种可能。

继续生活会保留这一轮已经建立的住处与关系。重新漫游会重置这一轮故事进展，同时保留回忆、已收集的结局和你们的亲密。

结局需要一路积累相遇与选择；仅仅把程序开着，并不等于自动完成所有故事。

## 让桌面更合你意

「小设置」里可以调整：

- **大小**：80%、100%、125%、155%。
- **剧情节奏**：30 分钟、1 小时、3 小时。
- **开机启动**：按需要开启或关闭。
- **爬前台窗口边**：允许她偶尔去合适的窗口边看看。
- **同步记忆**：把当前进展立即写入本机。
- **检查更新**：查看新版本；下载完成后显示「重启更新」。

窗口攀爬需要合适的前台窗口，暂不把桌面上的每个图标都当成可站立的平台。窗口关闭、最小化或移动后，她会结束这次攀爬，回到地面。

## 更新与记忆

安装版会在后台检查、下载新版。准备好后，在「小设置」点 **「重启更新」**：先保存记忆，再启动更新。普通退出不会顺便安装新版。

「同步记忆」指**本机保存**，目前没有账号或跨电脑云同步。换电脑前的备份方法、更新失败处理见 [常见问题](FAQ.md)。

## 键盘也能用

当斑斑或菜单已有焦点时，`Enter`、空格、菜单键或 `Shift + F10` 可以打开菜单；方向键选择项目。故事选项支持数字 `1–4`，`Esc` 可以收起故事或关闭菜单。长段对白可用左右方向键翻页。
